# ডাটাবেস আর্কিটেকচার ও স্কিমা (PostgreSQL + Drizzle ORM)

সমস্ত স্কিমা সংজ্ঞা `src/db/schema.ts`-এ এবং Drizzle কনফিগারেশন `src/db/drizzle.config.ts`-এ সংরক্ষিত আছে।

## প্রধান ১৯টি টেবিল

| টেবিল নাম | উদ্দেশ্য ও ব্যবহার |
| :--- | :--- |
| `users` | অনুমোদিত অ্যাডমিনিস্ট্রেটর, Google UID, bcrypt পাসওয়ার্ড ও ৫-স্তর RBAC রোল |
| `site_settings` | প্রতিষ্ঠান পরিচিতি, ব্র্যান্ডিং, পরিচালকের বাণী, অ্যাপ লিংক, পেমেন্ট, যোগাযোগ, সোশ্যাল, SEO ও ফিচার টগল |
| `highlights` | হিরো ৫ হাইলাইট কার্ড, "কেন আমাদের মাদরাসাকে বেছে নেবেন" এবং FAQ প্রশ্নোত্তর |
| `departments` | রওদাতুল আতফাল, কিতাব বিভাগ ও হিফজ বিভাগের তথ্য |
| `department_stages` | বিভাগসমূহের স্তর (যেমন: প্রাথমিক, মাধ্যমিক ও উচ্চতর স্তর) |
| `academic_years` | প্রতিটি স্তরের অধীন বর্ষ/শ্রেণি (যেমন: কিতাবের ৯ বর্ষ) |
| `curriculum_categories` | পাঠ্যক্রমের বিষয় শ্রেণি |
| `curriculum_items` | পাঠ্যক্রম বিবরণ ও আপলোডকৃত PDF লিংক |
| `fee_and_facilities_info` | অ্যাডমিন-নিয়ন্ত্রিত ফি/ছাড় নীতি এবং আবাসিক/অনাবাসিক সুবিধা |
| `admission_inquiries` | প্রাথমিক ভর্তি আগ্রহ (`ABM-ADM-YYYY-XXXX`), স্ট্যাটাস ও ERP সিঙ্ক অবস্থা |
| `notices` | নোটিশ বোর্ড, ক্যাটাগরি, পিন স্ট্যাটাস ও সংযুক্তি |
| `gallery_items` | পর্দা ও অনুমতির নিশ্চয়তাসহ ফটো ও ভিডিও গ্যালারি |
| `masala_categories` | মাসআলা-মাসায়েলের বিষয় শ্রেণি |
| `masala_questions` | স্বাধীন মাসআলা Q&A (`MAS-YYYY-XXXX`), গোপন PII কলাম ও মানব-অনুমোদন ফ্ল্যাগ |
| `complaints` | গোপনীয় অভিযোগ ও পরামর্শ (`CMP-YYYY-XXXX`) ও প্রশাসনিক উত্তর |
| `chatbot_knowledge` | চ্যাটবটের অনুমোদিত তথ্যভাণ্ডার (Database Grounded Knowledge) |
| `chat_conversations` | সরাসরি লাইভ চ্যাট ভিজিটর সেশন ও অপঠিত কাউন্ট |
| `chat_messages` | রিয়েল-টাইম চ্যাট বার্তার স্থায়ী রেকর্ড |
| `audit_logs` | প্রতিটি প্রশাসনিক কার্যক্রমের নিরীক্ষা লগ |

## গোপনীয়তা ও নিরাপত্তা নকশা
- `masala_questions` টেবিলে `questioner_name`, `address`, এবং `mobile_number` সংরক্ষণ করা হলেও পাবলিক এন্ডপয়েন্ট `GET /api/public/masala` থেকে এসব ফিল্ড কখনোই সিলেক্ট বা রিটার্ন করা হয় না।
- `is_published = true` এবং মানব-অ্যাডমিনের লিখিত `answer_text` ছাড়া কোনো মাসআলা পাবলিকে দেখানো হয় না।
