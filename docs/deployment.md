# প্রোডাকশন ডিপ্লয়মেন্ট ও পরিচালনা গাইড

## ১. বিল্ড ও স্টার্ট কমান্ড
```bash
npm run build
npm start
```
সার্ভারটি `server.ts` থেকে এক্সপ্রেস, Socket.IO ও স্ট্যাটিক `dist/` ফাইল পোর্ট `3000`-এ পরিবেশন করে (Node.js v22+ নেটিভ TypeScript সমর্থনসহ)।

## ২. নিরাপত্তার দিকসমূহ
- **হেলমেট ও CORS:** প্রোডাকশনে `helmet` হেডার এবং অনুমোদিত `APP_URL` সক্রিয় থাকে।
- **রেট লিমিটিং:** ফরম জমা এবং লগইন রুটে `express-rate-limit` প্রয়োগ করা হয়েছে।
- **RBAC:** প্রতিটি অ্যাডমিন রুটে সার্ভার-সাইড রোল ও মডিউল অনুমতি যাচাই বাধ্যতামূলক।
- **গোপনীয়তা:** প্রশ্নকারীদের ব্যক্তিগত তথ্য এবং অভিযোগ-পরামর্শ কোনোভাবেই পাবলিক API-তে প্রকাশিত হয় না।

## ৩. অবজেক্ট স্টোরেজ (S3/GCS) রূপান্তর
ডিফল্টভাবে আপলোডকৃত PDF ও ছবি `/public/uploads/{images,pdfs,documents}`-এ সংরক্ষিত হয়। প্রোডাকশনে `UPLOAD_STORAGE_DRIVER=s3` এবং `S3_BUCKET` এনভায়রনমেন্ট সেট করে স্টোরেজ অ্যাডাপ্টার সম্প্রসারণ করা যায়।

## ৪. প্রাথমিক সুপার অ্যাডমিন সংযোজন
`users` টেবিলে কেবল অনুমোদিত ইমেইল বা `super_admin` যুক্ত অ্যাডমিনরাই `/admin`-এ প্রবেশ করতে পারবেন। অতিরিক্ত অ্যাডমিন যুক্ত করতে সুপার অ্যাডমিন হিসেবে লগইন করে **অ্যাডমিন ও রোল (RBAC)** মডিউল ব্যবহার করুন।
