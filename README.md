# আসমা বিনতে আবু বকর (রা.) মহিলা মাদরাসা — ওয়েবসাইট, CMS ও ডিজিটাল সেবা প্ল্যাটফর্ম

> **আদর্শ নারী গঠনের প্রত্যয়ে** — কুরআন ও সুন্নাহর আলোকে প্রতিষ্ঠিত সালাফি মহিলা শিক্ষাপ্রতিষ্ঠান  
> ঠিকানা: মাদাম ব্রিজ, সদর, লক্ষ্মীপুর, বাংলাদেশ।

## প্রধান বৈশিষ্ট্যসমূহ

1. **১৬-সেকশনের পূর্ণাঙ্গ বাংলা পাবলিক ওয়েবসাইট** (`Hind Siliguri` + `Noto Serif Bengali` + Navy `#092F46`, Golden `#D9A323`, Ivory `#FFFEFA`, Soft Pink `#F4E5E9`)
2. **৩টি স্বয়ংসম্পূর্ণ একাডেমিক বিভাগ ও ডাইনামিক বিস্তারিত পেজ**:
   - রওদাতুল আতফাল বিভাগ (`/departments/rawdatul-atfal`)
   - কিতাব বিভাগ — ৯ বছর মেয়াদি, ৩ স্তর ও ৯ বর্ষ (`/departments/kitab`)
   - হিফজ বিভাগ (`/departments/hifz`)
3. **কারিকুলাম ও PDF সিলেবাস পোর্টাল**: ইন-ব্রাউজার PDF প্রিভিউ এবং সরাসরি ডাউনলোড
4. **প্রাথমিক ভর্তি আগ্রহ ও অনুসন্ধান ফরম** (`ABM-ADM-YYYY-XXXX`): কেবল প্রাথমিক আগ্রহ গ্রহণ করে; চূড়ান্ত ভর্তি মাদরাসায় সরাসরি সম্পন্ন হয়। ভবিষ্যতের ERP API সংযোগের জন্য প্রস্তুত।
5. **স্বাধীন মাসআলা-মাসায়েল Q&A মডিউল** (`MAS-YYYY-XXXX`):
   - প্রশ্নকারীর নাম, ঠিকানা ও মোবাইল নম্বর জনসম্মুখে কখনোই প্রকাশ করা হয় না।
   - কোনো AI স্বয়ংক্রিয় ফতোয়া/উত্তর প্রকাশ করে না—মানব-অ্যাডমিন/আলেমের লিখিত উত্তর ও অনুমোদনের পরই প্রকাশ হয়।
6. **দ্বি-স্তর বিশিষ্ট যোগাযোগ উইজেট**:
   - **স্বয়ংক্রিয় সহায়িকা (Chatbot)**: কেবল ডাটাবেসে অনুমোদিত তথ্যভাণ্ডার থেকেই উত্তর দেয় (কোনো তথ্য অনুমান করে না)।
   - **সরাসরি লাইভ চ্যাট (Direct Live Chat)**: Socket.IO ও PostgreSQL ভিত্তিক রিয়েল-টাইম চ্যাট এবং অ্যাডমিনের অনলাইন/অফলাইন উপস্থিতি নির্দেশক।
7. **গোপনীয় অভিযোগ ও পরামর্শ বক্স** (`CMP-YYYY-XXXX`): কেবল অ্যাডমিনিস্ট্রেটরের পর্যালোচনার জন্য সংরক্ষিত।
8. **২৫+ মডিউলের রোল-ভিত্তিক অ্যাডমিন ড্যাশবোর্ড (RBAC)**:
   - `super_admin`, `content_admin`, `admission_admin`, `qa_admin`, `communication_admin`
   - Firebase Google Sign-In + bcrypt পাসওয়ার্ড অথেনটিকেশন, ফাইল আপলোড এবং পূর্ণ অডিট লগ।

## বাস্তবায়নের অবস্থা (সম্পূর্ণ বনাম ক্লায়েন্ট তথ্য অপেক্ষমাণ)

### সম্পূর্ণভাবে বাস্তবায়িত ও কার্যকর
- [x] PostgreSQL (Cloud SQL) ১৯-টেবিল স্কিমা, সিড ও মাইগ্রেশন কাঠামো
- [x] Express + Socket.IO সার্ভার, Zod ভ্যালিডেশন, হেলমেট ও রেট-লিমিটিং
- [x] Firebase ID Token ও লোকাল অ্যাডমিন JWT ভিত্তিক ৫-রোল RBAC অথেনটিকেশন
- [x] সম্পূর্ণ ১৬ সেকশনের বাংলা পাবলিক ওয়েবসাইট, বিভাগ পেজ ও মাসআলা আর্কাইভ
- [x] ২৫+ মডিউলযুক্ত অ্যাডমিন ড্যাশবোর্ড, লাইভ চ্যাট কনসোল ও PDF/ছবি আপলোড
- [x] ফিউচার ERP ইন্টিগ্রেশন API (`/api/erp/*`) ও স্টোরেজ অ্যাডাপ্টার লেয়ার

### প্রতিষ্ঠানের কাছ থেকে প্রাপ্তব্য তথ্য/উপকরণ (অ্যাডমিন প্যানেল থেকে যুক্তযোগ্য)
- [ ] মাদরাসার অফিশিয়াল লোগো ফাইল (বর্তমানে জ্যামিতিক প্লেসহোল্ডার প্রদর্শিত হচ্ছে; **লোগো ও ব্র্যান্ডিং** মডিউল থেকে আপলোড করা যাবে)
- [ ] মাদরাসা ক্যাম্পাস ও শ্রেণিকক্ষের অনুমোদিত আলোকচিত্র (সততার নীতিতে কৃত্রিম ভবনের ছবি ব্যবহার করা হয়নি)
- [ ] অফিশিয়াল মোবাইল নম্বর ও ইমেইল ঠিকানা (`[এডিটেবল: ...]` অংশগুলো **যোগাযোগ ও ঠিকানা** মডিউল থেকে পরিবর্তনযোগ্য)
- [ ] পরিচালক / মুহতামিমের নাম ও স্বাক্ষরিত বাণী
- [ ] পৃথক **মোবাইল অ্যাপ** (Google Play URL) ও **পৃথক ওয়েব অ্যাপ** URL (**মোবাইল ও ওয়েব অ্যাপ** মডিউল)
- [ ] চূড়ান্ত পাঠ্যবই ও প্রসপেক্টাস PDF ফাইল (**পিডিএফ ও নথি আপলোড** মডিউল)
- [ ] অনলাইন পেমেন্ট গেটওয়ে (SSLCommerz / bKash Merchant) ও বাহ্যিক ERP API কী
